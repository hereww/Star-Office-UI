# 橘猫四向行走方向模板 v1

记录日期：2026年10月1日。来源：本项目四向行走与工位办公预览的四张行走卡片。

## 用户本次确认

> 工位办公的动画肯定还是有问题的。行走方向可以了 作为模板记录保存

## 已保存的模板

| 方向 | 视觉规则 | 参考图片 |
| --- | --- | --- |
| up | 背面，面向地图上方 | up/A.png、up/B.png |
| down | 正面，面向地图下方 | down/A.png、down/B.png |
| left | 严格左侧面 | left/A.png、left/B.png |
| right | 严格右侧面 | right/A.png、right/B.png |

每个方向保存实际已有的A/B两张96×96 RGBA参考图，共8张；复制件SHA-256与预览及原素材一致，没有重画、缩放、镜像或复制凑12帧。

## 后续使用

- 同一橘猫身份母版继续使用Skill原有orange-cat-reference.png；本包提供朝向与姿势参考，不自动替换角色身份母版。
- 生成对应方向时，附母版与该方向A/B图，保持上背面、下正面、左右严格侧面，不产生额外斜向。
- 新动作仍按每方向独立12帧、4列×3行、12fps预览制作。不能将本包两张姿势标成完整12帧循环。
- 未通过的工位办公v2不得作为办公模板，也不能因行走方向认可而视作已认可。

本次认可范围是四方向模板；完整行走循环、首尾接缝和生产接入仍未由这次确认批准。down-v7完整旧失败稿不属于本包。

详细版本、原始路径及哈希见template-manifest.json。冻结v1文件；后续改版另建版本，保留本次确认记录。
