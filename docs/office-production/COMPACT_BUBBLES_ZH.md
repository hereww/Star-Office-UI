## 最新显示约定

- 一行 `用户名：X`。X 只表示采样时刻当前并发，不表示历史对话总数、Token 增量或任务完成数。
- 不显示用户 ID、工位号、状态句、“正在处理”或“条工作中”等多余文本。
- 可信零值为 `用户名：0`；未知、未跟踪、失败或过期并发为 `用户名：—`，绝不伪造空闲。
- 插件姓名为空时为 `未设置：X`；身份不可用时为 `用户名未知：—`。不取邮箱、ID 或别名补名。
- 短用户名在实际 1280×720 全景中完整显示；长姓名仅省略姓名部分，数值保留字符串精度，选中详情显示完整姓名。
- 气泡横向中心对齐自己的角色头部/工位；拥挤时仅附近上下错开，不转移到其他房间或全局避让轨道。
- 实测气泡高度不超过 28 CSS px、宽度不超过 114 CSS px；保留轻微浮动与减少动态模式。
- V4 地图、桌椅、角色四向、表情/屏幕素材及原动画时钟不变。RC7 相对 RC6 的发行源变化仅为部署说明纠正文案，运行时代码字节一致。
