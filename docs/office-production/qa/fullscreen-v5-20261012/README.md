# V5 纯地图全屏验收

日期：2026-10-12（北京时间）。仅修改本地 V5 员工页面，没有部署服务器。

## 变更

- 全屏目标由整个 `office-app` 改为 `office-map`，其中只有 Phaser canvas。
- 顶部品牌/统计、详情栏、视角切换、工位列表、页脚、地图底部说明及预览标识不进入全屏。
- 全屏地图铺满视口，无边框、圆角、外边距或滚动条；缩放、拖动和工位 hover 保留。
- 退出全屏后恢复正常页面和按钮焦点；地图加载完成前禁用全屏按钮。
- 增加 Esc 退出兼容处理，避免嵌入式浏览器只向网页派发 Esc 而不退出全屏。

## 验收证据

- `acceptance.json`：V5 员工页 14 项浏览器检查，覆盖全屏目标、纯 canvas 子节点、全屏四角遮挡检测、DPR2 画布尺寸、拖动/hover、Esc 退出和操作界面恢复。
- `v5-employee-fullscreen-hover.png`：纯地图全屏；隔离模拟数据，仅作界面验收。
- `v5-employee-fullscreen-exited.png`：退出后恢复操作界面。
- 当前 Codex 内置浏览器中使用既有内网匿名快照手动验证：进入全屏后 AX 树只剩地图和图像；Esc 退出后恢复操作界面，焦点回到全屏按钮。
