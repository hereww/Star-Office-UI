# 七品种小猫候选概念板

这是以 `approved-office-expressions-v1` 橘猫固定坐姿图集为比例参考生成的**视觉提案**，不是生产动画图集。

从左到右：布偶猫、英短、美短、狸花猫、奶牛猫、狮子白猫、简州猫。

## 当前边界

- 只用于后续 AI 生成方向评审；不直接接入播放器。
- 后台目录中的七个 profile 仍保持 `prompt-ready` / `assignable=false`。
- 每个候选要进入生产，仍需独立完成透明底图、`idle/working/syncing/error` 的 4×3 12 帧图集、四向资源/锚点和运行时像素 QA。
- 工位、屏幕效果和 expression-only 逻辑不因概念板而改变。
