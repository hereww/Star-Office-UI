# 七种猫静态概念图

完成日期：2026-10-14。

七张素材分别使用原生图像生成工具制作，参考原七猫概念板与本轮布偶猫统一风格。每张保留独立生成原图，透明背景、正面坐姿；文件以原始字节复制至后台素材目录。

打开 `index.html` 可比较七种角色。`metadata.json` 记录尺寸、透明留白与 SHA-256。原生输出的背景有少量 alpha 不超过 8 的近透明像素，留白按可见像素阈值 8 检查；保留图工具输出原始字节。

静态概念图可在后台动画预览中查看。四向坐姿、状态表情图集尚未制作，因此仍保持 `productionReady=false`、`assignable=false`。
