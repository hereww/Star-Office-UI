# 纵向连排桌新候选（红区，4对/8席）

单次内置 image_gen 生成；透明 furniture-only PNG。原始生成和运行时PNG字节一致，未裁切、旋转、重绘或插值。没有编辑角色、地图、运行时代码。

- 实际尺寸：887×1774，**非原生4K**。
- 桌面可见范围约 [234,92,655,1564]；中央隔板 [426,78,462,1636]。
- `seatContacts[].point` 是建议椅子/躯干中心，`deskEdgeContact` 是靠桌接触点；不要直接当作现有角色的脚底 poseAnchor。
- 奇数席在左，角色面向右；偶数席在右，角色面向左。四组中心 y=300/667/1035/1398。
- `screens[].polygon` 保守限制在真正可见的浅青侧屏条内；面积极窄，适合低强度状态闪烁，不适合文字面板。
- `screens[].led` 对应可见但较弱的青色下边框细节，逐席定位。
- 含8台直立薄屏/8个实体键盘/8个鼠标，无第二屏/平板；数量来自人工目视技术检查，并非用户验收。
- 有极低alpha的外围毛边，alpha>=16范围更紧；未为此改图。
- 键帽风格化且空格键区分较弱，角色遮挡和键盘接触尚需运行时合成检查。

`integrationAllowed:true` 表示可接入候选预览；`humanApproved:false`、`visualApproved:false`。不表示已接入当前场景或已通过用户视觉验收。
