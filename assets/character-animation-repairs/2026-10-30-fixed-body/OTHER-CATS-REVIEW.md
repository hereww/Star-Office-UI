# 其他七个品种的逐帧复审

本轮以已推送的 `feee01c` 为起点，检查布偶、英短、美短、狸花、奶牛、狮子白猫和简州猫。范围为 7 品种 × 4 朝向 × 4 动作，共 112 套、1344 帧。除像素合同外，复审了全部可见方向的脸部截图与真实 V5 播放器缩放，避免把“图集有变化”当成表情质量合格。

## 确认的问题

| 品种/范围 | 修复前的可见问题 |
| --- | --- |
| 布偶 | 左右休息表情出现双鼻；右侧闭眼仍露出蓝色原虹膜。 |
| 英短 | 左侧休息出现双鼻；正面休息的原金色眼圈未清干净。 |
| 美短 | 正面休息贴入另一张错位脸，额头有椭圆接缝；左侧休息在图集换行和回环时脸纹跳位；闭眼留有绿色原虹膜。 |
| 狸花 | 闭眼残留原眼圈；正面新睡嘴两侧仍有旧微笑端点。 |
| 奶牛猫 | 闭眼线与深色填充几乎同色，休息状态成为深色眼块；旧嘴端点未完全清除。 |
| 狮子白猫 | 正面睡嘴残留旧端点；原尺寸可见的 1 像素闭眼线，经 V5 缩放后断成小点。 |
| 简州猫 | 闭眼眼窝为明显平涂色块，旧嘴端点残留。 |
| 全部七个品种的背面 | 非工作状态仍有历史 alpha 重复相乘；工作态也有 RGB 差异。状态切换时背面边缘与颜色不一致。 |

美短左侧旧休息图集的换行/回环差异分布在额纹、脸颊和下颌，不是正常嘴部表情变化。布偶等旧脸层的五官偏移也不是运行时位移：静态身体已经固定，但整块脸部素材仍会覆盖错位的鼻子与花纹。

## 修复方法

- 保留母版真实睁眼像素，在实测的眼部范围内完成眨眼；旋涡只绘制在原眼内部。
- 原鼻、额纹、脸颊、头部轮廓和身体保持母版 RGBA。休息嘴只修改实测嘴区，完整清除原嘴端点。
- 仅取历史素材中的局部闭眼及邻近毛色，重新对齐眼位；不再将整张旧脸贴入。缺失方向的局部来源取自历史完整 idle 图集的指定母帧，原图 SHA、提交、帧号及裁剪坐标均记录在 `sources.json`。
- 对深毛和白毛分别保证眼睑可读性；白猫使用显式的 2 像素源笔画，避免正常缩放丢线。
- 28 套背面图集逐像素复制原母版 RGBA，四种状态保持同一个姿态与边缘。
- 运行时继续只读取 192×192 完整帧，没有重新引入脸层、手部、行走或家具改动。

中间候选中的浅色眼罩、竖向色带和夹入的旧嘴黑点被视觉复审拒绝，没有写入正式 PNG。母版中的极低 alpha 游离像素在正常播放比例不可见，本轮保留母版，未把正常抗锯齿一并清除。
