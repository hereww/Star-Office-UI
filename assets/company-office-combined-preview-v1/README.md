## 适配规则

工位外观使用原静态层。寻路用家具**实际占地**，而不是把192×192透明画布全当实体：椅子和桌子的占地合并为 `[cx-84,cy-53,169,127]`，脚底碰撞半径18px，四邻格步长16px。路径段还按4px采样检查，避免跨格穿薄墙。

墙体按原布局，并加前景遮挡条；椅子/桌子与移动角色按脚底Y排序。站姿脚底坐标和坐姿工位坐标分开，入座/离座只做两种已有素材的模式切换，**没有新增起身/坐下过渡动作**。

### 验证方法边界

手机检查是浏览器视口和浏览器原生拖动，**不是物理手机触控测试**。浏览器逐帧截图记录于 `browser-expression-screenshots.json` 与 `qa-frames/`，返回格式为有损JPEG，不能靠截图哈希判断身体是否移动。精确像素结论以 `pixel-qa.json` 无损渲染为准；截图用于视觉核对。初次工作状态截图未覆盖帧11，不宣称该批截图独立覆盖全部48个唯一帧；该帧由72帧无损测试覆盖。
