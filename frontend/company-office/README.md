# 公司办公室运行时

这里存放新版地图、角色、家具、屏幕效果和运行时适配器。页面入口在 `frontend/office/`；本目录不直接处理 HTTP 会话、管理员权限或轮询。

## 运行时边界

- `connected-v5/`：当前连排工位场景。拥有当前角色模板、独立屏幕层、摇滚房间和生产地图运行时。
- `connected-v4/`：共享家具/座位契约、遥测桥和兼容测试边界。V5 适配器复用其中的元数据和气泡桥，因此不能按“旧版本目录”删除。
- `reference-v3/`：基础角色合成、屏幕效果、字体、参考布局和冻结回归资源。
- `character-profile-*`：角色目录、素材加载和运行时 profile 校验。
- 根目录 `runtime.mjs`、`seated-compositor.mjs`：旧版页面/Electron 兼容路径；新版页面不直接从这里启动地图。

## 当前页面如何进入这里

`frontend/office/map-loader.mjs` 是唯一的新版地图装配点。它负责同源资源校验、Phaser 加载、运行时创建、适配器连接、拖动/缩放交互和销毁。新增场景或资源时，先更新这里的路径表和对应 manifest，再写页面调用；不要在 `employee.mjs`、`admin.mjs` 里复制地图初始化逻辑。

## 修改规则

1. 角色、家具和屏幕的坐标必须留在对应运行时或 manifest；页面只传递快照和显示偏好。
2. V5 需要复用的 V4 逻辑必须通过明确的 import 或 facade，不能复制一份隐式分叉。
3. `reference-v3` 的冻结资源改动必须有像素/契约回归；候选素材只放 `assets/` 或页面概念预览。
4. 所有运行时资源必须能被发布闭包解析；不要使用根目录绝对路径、外部 URL 或 `.local` 路径。
5. `destroy()`、事件监听和 Phaser 游戏实例必须成对清理，避免管理员页面切换后残留监听器。
