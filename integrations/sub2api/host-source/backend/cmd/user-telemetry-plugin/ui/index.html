用户数据输出

仅配置授权范围，不修改模型请求、路由或计费。

输出五类数据：邮箱、用户名、API Key 元数据、Token 用量、用户并发。

API 仅含 ID、名称和状态；不输出明文密钥、密码、OAuth 凭据或模型正文。消费端访问授权由宿主管理。

每行一个，或用逗号分隔；1–500 个不重复的正整数 ID，不接受邮箱。默认无授权范围，不能启用。

IANA 时区，例如 Asia/Shanghai 或 UTC。

1–500；留空使用默认值。
